Política de Privacidade – Clipador Viral

Atualizado em 20 de novembro de 2026

1. Dados que o aplicativo usa

Ao conectar o TikTok, o aplicativo recebe do TikTok um token de acesso e informações básicas do perfil (nome de exibição e foto), para identificar a conta conectada e enviar vídeos como rascunho.

2. Onde os dados ficam

O Clipador Viral roda no computador do próprio usuário. Os tokens e os vídeos ficam armazenados somente nesse computador. Não há servidor central, e nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

3. Uso dos dados

Os dados do TikTok são usados apenas para enviar para a conta conectada os vídeos que o usuário escolheu enviar.

4. Como remover o acesso

O usuário pode desconectar a conta dentro do aplicativo, ou revogar o acesso nas configurações do TikTok (Segurança e permissões > Apps e serviços). Ao desconectar, o token é apagado do computador.

5. Serviços de terceiros

A escolha de cenas pode usar a API do Claude (Anthropic), que recebe a transcrição do vídeo a ser cortado. Nenhum dado de conta do TikTok é enviado a esse serviço.

6. Alterações

Esta política pode ser atualizada. A versão em vigor é a publicada nesta página.
